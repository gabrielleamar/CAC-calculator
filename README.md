# Statin Decision & CAC Screening Calculator

A clinical decision support tool for medical students and healthcare providers to determine whether coronary artery calcium (CAC) scoring is beneficial for patients and guide statin therapy decisions.

## Features

- **Multi-step clinical decision tool** based on 2026 ACC/AHA Guidelines
- **Automatic statin indication detection** for high-risk patients
- **Age-stratified assessment** (40-75 years vs. under 40)
- **10-year ASCVD risk calculation** using Pooled Cohort Equations
- **Risk-enhancing factor assessment** for refined risk stratification
- **CAC scoring recommendations** with clinical guidance
- **Pre-statin checklist** with contraindications, drug interactions, and monitoring
- **Evidence-based information** on CAC scoring and statin therapy
- **Nonstatin alternatives** for statin-intolerant patients

## How to Use

1. Open `cac-calculator.html` in any web browser
2. Follow the 5-step process:
   - Step 1: Check for automatic statin indications
   - Step 2: Calculate ASCVD risk (or assess risk factors for patients under 40)
   - Step 3: Evaluate risk-enhancing factors
   - Step 4: Determine if CAC scoring is recommended
   - Step 5: Review final statin therapy recommendation

## Deployment

### GitHub Pages

To deploy this to GitHub Pages:

1. Create a new repository on GitHub
2. Upload `cac-calculator.html` to the repository
3. Go to repository Settings → Pages
4. Under "Source", select "Deploy from a branch"
5. Choose `main` (or `master`) branch and `/ (root)` folder
6. Click Save
7. Your site will be available at `https://yourusername.github.io/repository-name/`

### Netlify (Alternative)

1. Go to [netlify.com](https://www.netlify.com) and sign up
2. Drag and drop `cac-calculator.html` onto the dashboard
3. Your site will be instantly published

## Guidelines Reference

This tool is based on the 2026 ACC/AHA Guideline on the Management of Dyslipidemia and incorporates recommendations from:
- ACC/AHA Primary Prevention Guidelines
- Pooled Cohort Equations (PCE)
- Multiethnic Study of Atherosclerosis (MESA)
- CLEAR Outcomes Trial (bempedoic acid)
